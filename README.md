# Equal-block extensions of Colbrook's refutation of the Mourad–Abbas spectral conjecture

**Authors:** Haobo Ma, Wenlin Zhang

Extending Colbrook's counterexample of September 11, 2026 (Theorem IS-02, Sections 1–2), we refute Mourad and Abbas's Conjecture 5.1 (arXiv:1310.1273v1, p. 10) by a continuous equal-block family, using a component-size constraint for stochastic idempotents and a four-cycle perturbation. For integers k,r >= 2, put A_{k,r}(t) equal to the direct sum of r copies of t I_k + (1-t) C_k, where C_k has zero diagonal and off-diagonal entries 1/(k-1). We prove the exact classification: for 0 <= t <= 1, this matrix is determined, up to permutation similarity, among all similar doubly stochastic matrices if and only if t < 1/k^2 or t = 1. Using the classical integer-partition structure of diagonalizable doubly stochastic matrices with two distinct real eigenvalues, we obtain the two-eigenvalue part of the source's zero-trace question. When k >= 4 and 0 < t < 1/k^2, it has positive trace but lies on none of the segments in the conjecture. Explicit unequal-block matrices explain the sharp endpoint.
